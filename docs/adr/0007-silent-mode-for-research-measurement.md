# A silent mode that records technique without giving feedback

The app can run a set that detects and records every error but shows no alerts and no error breakdown in the set summary. The research uses a pretest/posttest design: technique must be measured before and after four weeks of feedback, and those measurements are only valid if the app does not coach the user during them. A professional can switch it on for a linked user's measurement sessions.

**Consequences:** silent mode is a core research feature, not a mute toggle (that is a separate setting that only turns off the sound). Detection, counting and storage must behave identically with or without it; only the presentation changes.

Source: Análisis "Decisiones de alcance", RF-23, RF-46; Marco Metodológico §1.3.
